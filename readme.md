### UI Changes from the Original BO2 Version
I made some light modifications to adapt the design to BO1 while staying as faithful as possible:

- Font couldn't be perfectly replicated due to BO1 limitations
- Added a clean green line separator under the menu title and options

I tried to recreate the feel and layout of the original Revolution menu as closely as the constraints of BO1 GSC allow. The menu is still actively updated — make sure to check the [Releases](https://github.com/a5x/BO1-Zombies-Mod-Menu-PS4/releases) section regularly for the latest version!

## Installation & Requirements

 - **Need Jailbroken/Devkit/Testkit console**
 - **GoldHen (minimum an 2026 update) for jailbroken console**

### Installation Steps

1. **Injector Setup**  
   Go to the [BO1 PS4 Auto Injector](https://github.com/ItsJokerZz/DeadOps/) repository and download the injector.  
   Follow the installation instructions provided in that repo.  

2. **Place the GSC File**  
   - Open **FileZilla** and connect to your PS4.  
   - Navigate to `/data/DeadOps/t5_cp/maps/`  
   - Place your mod menu file in this folder
   - edit your plugins.ini and add this : [CUSA57547] /data/GoldHEN/plugins/DeadOps.sprx
   - and in /data/GoldHEN/plugins/ add DeadOps.sprx

3. **Inject the Menu**  
   - Launch **Black Ops 1**.  

4. **Start Playing**  
   Go into **Zombies** and enjoy the menu.

### Tips
- Make sure the injector is running properly before launching the game.
- Always use the latest version of both the injector and the mod menu.
